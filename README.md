# 🎂 Happy Birthday — 3D Interactive Celebration

A stunning, interactive 3D Web Application created to celebrate ** Birthday**! Featuring a 3D rotating carousel of customized cartoonistic anime portraits, interactive surprise gift modals, glowing WebGL shader animations, and vibrant confetti explosions.

## ✨ Features

- **🎨 3D Rotating Cartoon Carousel**:
  - 10 custom-generated cartoonistic & anime-style portraits (`r1.png` to `r10.png`) set in a 3D cylindrical perspective.
  - Full touch & pointer controls: drag to spin, scroll to zoom in/out, and smooth inertia physics.

- **🎁 Interactive Bouncing Gift Box**:
  - Floating 3D Gift Box card embedded in the spinning carousel with custom pink glow and bounce animations.
  - Clicking the Gift Box opens a **Surprise Gift Modal** for Lishu and launches multi-colored confetti explosions.

- **💌 Fixed Message Overlay**:
  - Always-accessible floating message button with quick-access popup letter.
  - Displays a heartfelt birthday message tailored for **Lishu** and triggers pink heart confetti.

- **🌌 WebGL Animated Background Shader**:
  - Custom GLSL Fragment Shader rendering a glowing mathematical heart curve with dynamic color shifts.
  - Floating particle fireworks and rising canvas hearts.

- **📱 Fully Responsive**:
  - Optimized for mobile touch screens, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3 (3D Transforms & Glassmorphism)
- **Graphics & Shaders**: WebGL GLSL Shaders, HTML5 2D Canvas Context
- **Effects & Libraries**: [Canvas Confetti](https://cdn.jsdelivr.net/npm/canvas-confetti)

## 🚀 How to Run Locally

1. **Clone or Download** this repository.
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
3. Click and drag anywhere on the screen to rotate the 3D photo carousel!
4. Click the **Gift Box** card or the **Message** button to unlock surprises and confetti!
